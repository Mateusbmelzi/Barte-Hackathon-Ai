# PROMPTS: histórico das sessões de IA

O edital exige o histórico de **todas** as sessões de IA (construção e preparação), sem edição além da remoção de chaves de API e dados pessoais.

Onde colocar:
- Transcripts exportados do Claude Code (ex.: `/export` ou os `.jsonl` da sessão): nesta pasta, um arquivo por sessão, nomeado `AAAA-MM-DD_HHhMM_<assunto>.md` (ou `.jsonl`/`.txt`).
- Links de conversa: listar em `links.md` nesta pasta, com data e assunto.
- Prints: subpasta `prints/`.

`MOMENTOS.md` marca de 2 a 4 momentos que importaram, com pelo menos um em que a IA errou.
