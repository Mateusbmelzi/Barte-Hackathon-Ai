Ferramenta interna do financeiro

Fechamento mensal — Tarvo

Envie os arquivos do mês (a Orbe pode mandar mais de um), clique em “Rodar fechamento” e baixe as planilhas prontas. Os arquivos que você enviar não são alterados.

1 Arquivos de entrada

Arraste os arquivos para a área abaixo (pode ser todos de uma vez) ou clique para escolher.

    2 Rodar o fechamento

    O botão fica disponível quando pelo menos um arquivo do mês estiver reconhecido. Se faltar algum (Orbe, taxas, Ponte, plano de contas ou extratos), o fechamento sai parcial: fecha o que não depende dele, marca o provisório e mostra o que ficou bloqueado. Leva poucos segundos.

    3 Arquivos para baixar

    Para abrir no Excel sem estragar valores e CNPJs, use Dados → Obter Dados → De Texto/CSV (veja o COMO_USAR.md).

      Baixar tudo (.zip)

      4 Investigação de divergências

      Para cada grupo de divergência: à esquerda, os fatos calculados pelo fechamento; à direita, as hipóteses de causa sugeridas pela IA. Você aceita ou recusa cada hipótese. Nada aqui altera os arquivos do fechamento.
