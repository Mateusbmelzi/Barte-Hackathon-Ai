# Contratos de clientes

Aqui ficam os contratos enviados para a leitura da IA, em `cadastro/contratos/<cnpj>/<arquivo>` (o upload e copiado sem
sobrescrever; se o nome repetir, vira `_v2`, `_v3`...). Contratos reais podem ser sensiveis: o conteudo desta pasta
NAO e versionado (ver `.gitignore`). O contrato ficticio de demonstracao esta em
`tests/fixtures/contrato_ficticio_exemplo.txt`.
